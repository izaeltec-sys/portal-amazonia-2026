# Logotipos oficiais do projeto institucional

Adicionar neste diretório, sem alterar seus pixels ou proporções, os arquivos originais fornecidos:

- `associacao-eec.png` — imagem oficial da associação (no desenho original aparece E.E.C).
- `legado-polaco.png` — imagem oficial Polaco Cycling Team Eventos.

A página `../index.html` já os referencia nestes nomes. Não gerar substitutos, não redesenhar e não alterar o logotipo da associação para inserir o “A”; usar a sigla AEEC no texto institucional.

Para anexar, abrir este diretório no GitHub, selecionar **Add file → Upload files**, escolher os dois PNGs originais e confirmar o commit na branch principal.
